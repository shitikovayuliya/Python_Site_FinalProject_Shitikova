## Описание

Это учебный дипломный проект — веб-сайт платформы для краткосрочной аренды вещей. Пользователи могут публиковать объявления о сдаче вещей в аренду, отправлять заявки на аренду, оставлять отзывы и управлять бронированиями.

## Функционал

- **Объявления** — создание, редактирование, удаление, модерация объявлений
- **Категории** — группировка объявлений по категориям
- **Поиск и фильтрация** — по названию, описанию, локации и цене
- **Бронирования** — система заявок на аренду с подтверждением владельцем
- **Отзывы** — рейтинг и комментарии к объявлениям
- **Аутентификация** — регистрация, вход, выход
- **Модерация** — одобрение/отклонение объявлений для staff

## Технологии

- **Backend:** Python 3.9, Django 4.x
- **Database:** PostgreSQL 15
- **Deployment:** Docker, Docker Compose

## Быстрый старт

```bash
# Запуск через Docker Compose
docker-compose up --build -d

# Применение миграций
docker-compose exec web python manage.py migrate

# Создание суперпользователя
docker-compose exec web python manage.py createsuperuser

# Запуск тестов
docker-compose exec web python manage.py test
```

## Доступ

- Главная страница: http://localhost:8000
- Админ-панель: http://localhost:8000/admin/
